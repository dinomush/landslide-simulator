Read the mathematics

∇Z = [∂Z/∂x, ∂Z/∂y]
θ = atan(|∇Z|)
D = −∇Z / |∇Z|

More saturation raises pore pressure and lowers FoS. Particles accelerate along D when FoS < 1, with velocity damping.
